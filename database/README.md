# PostgreSQL

Для пустой базы выполните schema.sql, затем 002_checkout.sql, затем seed.sql с psql -v ON_ERROR_STOP=1. Docker Compose делает это автоматически при первом запуске с пустым томом.

Для базы с уже созданной исходной схемой примените только 002_checkout.sql один раз, затем при необходимости seed.sql. Seed не перезаписывает существующие товары. Миграция добавляет stock, guest_sessions, guest_cart_items, orders и order_items. Исходная таблица cart_items сохранена, но API её не использует.

Цены товаров хранятся в NUMERIC(12,2) USD; снимок цены и сумма заказа — в целых центах BIGINT. В seed 8 товаров и 5 категорий, начальный остаток — 50 единиц каждого товара.

Полные инструкции запуска и проверки находятся в ../README.md.
